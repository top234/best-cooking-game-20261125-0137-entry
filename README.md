**Warung Senja** — a cozy original cooking game. You run a small food stall at
dusk: take orders from the board, grab ingredients from the crates, chop them on
the board, cook them in the wok, plate the dish and serve it before the
customer's patience runs out. Four original recipes — Nasi Goreng Senja, Mie
Kuah Pelangi, Sate Ember and Es Teh Melati — a 150-second day, coins, score and
combos for fast, patient service. All art is drawn in code on a 2D canvas and
all sound is made with WebAudio oscillators; there are no outside assets and no
network requests.

## Run it

```sh
npx serve game
```

or, without installing anything:

```sh
cd game && python3 -m http.server
```

then open `index.html` in desktop Chrome. Click the stations with the mouse,
or press `1`–`6` to grab an ingredient, `Space` to start, `P` to pause, `R` to
restart the day, `M` to mute.
